# איקס-עיגול (Tic-Tac-Toe)

משחק איקס-עיגול בטרמינל בפייתון. אפשר לשחק מול חבר או מול המחשב.

המחשב בוחר מהלכים עם אלגוריתם minimax, כך שהוא משחק באופן אופטימלי ולא מפסיד אם שני הצדדים משחקים נכון.

## דרישות

- Python 3

אין צורך בספריות חיצוניות.

## הרצה

מתיקיית הפרויקט:

```bash
python Tictactoe.py
```

אם במערכת שלך הפקודה היא `python3`:

```bash
python3 Tictactoe.py
```

## איך משחקים

1. בוחרים מצב:
   - `1` — שני שחקנים על אותו מחשב
   - `2` — שחקן מול המחשב
2. במצב מול מחשב אפשר לבחור לשחק כ־`X` (מתחיל) או כ־`O`.
3. בכל תור בוחרים משבצת לפי מספר בין `1` ל־`9`:

```
1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9
```

4. המשחק מסתיים בניצחון או בתיקו. אפשר לשחק שוב עם `y`.

## קבצים
