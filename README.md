# איקס-עיגול (Tic-Tac-Toe)

משחק איקס-עיגול עם ממשק גרפי בפייתון. אפשר לשחק מול חבר או מול המחשב.

המחשב בוחר מהלכים עם אלגוריתם minimax, כך שהוא משחק באופן אופטימלי ולא מפסיד אם שני הצדדים משחקים נכון.

## דרישות

- Python 3
- Tkinter (כלול בדרך כלל עם פייתון)

אין צורך בספריות חיצוניות.

## הרצה

מתיקיית הפרויקט:

```bash
python Tictactoe.py
```

אם במערכת שלך הפקודה היא `python3`:

```bash
python3 Tictactoe.py
```

ייפתח חלון משחק. אם רץ עותק ישן בטרמינל, סגרו אותו והריצו מחדש.

## איך משחקים

1. בוחרים מצב בראש החלון:
   - **שני שחקנים** — שני שחקנים על אותו מחשב
   - **מול המחשב** — שחקן מול יריב ממוחשב
2. במצב מול מחשב אפשר לבחור לשחק כ־`X` (מתחיל) או כ־`O`.
3. לוחצים על משבצת בלוח כדי לשחק.
4. קו ניצחון מסומן בירוק. הניקוד מתעדכן בראש החלון.
5. **משחק חדש** מתחיל סיבוב נוסף בלי לאפס את הניקוד. החלפת מצב משחק מאפסת את הניקוד.

## קבצים

- `Tictactoe.py` — לוגיקת המשחק, הממשק הגרפי והיריב הממוחשב
